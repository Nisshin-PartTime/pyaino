# pyaino で Qwen 小型モデル：推論・学習・LoRA の実験

実施日: 2026-11-12 / CPUのみ（40コア, OPENBLAS_NUM_THREADS=16）, float32
モデル: Qwen2.5-0.5B-Instruct（推論と勾配の照合は Qwen3-0.6B でも実施）

## 正しさの検証（pyaino/test）

| テスト | 内容 | 結果 |
|---|---|---|
| `test_Qwen_numpy_only.py` | 小さな乱数Qwen2/3（float64）で、有限差分による勾配検査、KVキャッシュ、LoRA保存/マージ、`cf.save/load_parameters` を確認 | 勾配の相対誤差 ≤1.5e-7、キャッシュの差 ~1e-15 |
| `test_Qwen_vs_transformers.py` | HF transformers（fp32）と logits・貪欲生成・全パラメタ勾配・LoRA勾配を照合 | logits 1e-5、生成 24/24 トークン一致、勾配 ≤2e-4（両モデル） |
| `test_Qwen_peft_export.py` | `export_peft` で書き出したアダプタを transformers+peft で読み込み、logits を比較 | 相対誤差 1.1e-5、argmax 100% 一致 |

## 速度（Qwen2.5-0.5B, fp32）
- CPU（16スレッド。40スレッドでは逆に遅い）: 生成 約4.5〜6.5 tok/s、LoRA学習1ステップ（約840〜980トークン）約17〜18秒、全パラメタ 約30秒（メモリ約10GB）
- SX-Aurora VE 1枚（NLCPy）: 生成 約8 tok/s、LoRA学習1ステップ（976トークン）約3.9秒
  - 実行方法は `documents/pyaino_SX-Aurora対応_20261112.md`。`bash tools/sx_aurora/run_ve.sh <venv> experiments/qwen/run_experiment.py --mode lora` のように動かす

## 実験：pyaino の知識を教える（`run_experiment.py`）
- 学習データ: README から作った8つの事実 × 質問2通り = 16例
- 評価データ: 学習に使っていない言い換え質問8例
- 共通条件: 24ステップ、バッチ8、AdamT、cosine学習率、全体の勾配ノルムを1.0でクリップ
- 一般NLL: 無関係な一般質問4問に対する、学習前のモデル自身の回答のNLL（上がるほど元の能力が劣化）

| 手法 | 学習パラメタ | 学習率 | eval損失 | 一般NLL | 学習時間 |
|---|---|---|---|---|---|
| 学習前 | – | – | 3.366 | 0.617 | – |
| LoRA r=8 (q,k,v,o,gate,up,down) | 4.4M (0.9%) | 2e-4 | 0.755 | 1.063 | 約7分 |
| LoRA + replay（自己応答8例を混ぜる） | 4.4M | 2e-4 | 1.065 | **0.699** | 約8分 |
| 全パラメタ ※ | 494M | 1e-5 | **0.128** | 1.298 | 約12分 |

※ 全パラメタ学習のみ、pyaino流に書き直す前のコードで実行した（数値の挙動は書き直し後とほぼ同じことを LoRA で確認済み）。

### 観察
- **全パラメタ学習**は学習データをほぼ暗記した（学習損失 0.003）。言い換え質問にも多くは正しく答えるが、事実の取り違えがあり、一般能力の劣化が最も大きかった（リスト逆順の質問に Qwen の話をするなど）。
- **LoRA** は損失が大きく下がったが、生成では「NumPyとPaddlePaddle」のような作り話が残り、無関係な質問にも pyaino の用語が混ざった。
- **replay** は一般能力の劣化をほぼ抑えた（一般NLL +0.45 → +0.08、一般質問の回答もほぼ元どおり）。ただし知識の定着は弱まり、生成はまだ不正確だった。
- 16例・24ステップという小規模な設定では、知識の注入と一般能力の保持はトレードオフになった。改善するなら、データの量と言い換えを増やす、ステップ数を増やす、replay の比率を調整する、などが考えられる。
- ベースモデル自身も「1〜10の和」で途中に誤った値を出しているので、この質問は劣化の指標としては参考程度。

結果の詳細（損失の推移、学習前後の生成例）は `results/*.json` を参照。
